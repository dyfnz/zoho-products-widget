How to Use

  1. Click in the input field to focus it
  2. Start typing a manufacturer name (e.g., "Cisco" or "Fort")
  3. The datalist will filter to show matching options
  4. Click an option or use arrow keys + Enter to select
  5. You can also type a custom value not in the list

Browser Styling Limitations

  • Dropdown appearance varies by browser: Chrome, Firefox, Safari, and Edge each render the datalist dropdown differently. There is no CSS control over the dropdown styling.
  • No custom option formatting: Unlike custom dropdown components, datalist options cannot include icons, badges, or rich formatting.
  • Mobile behavior: On iOS and Android, the datalist may appear as a native picker, which can be quite different from desktop.
  • Keyboard navigation: Works well, but the visual feedback during keyboard navigation is browser-controlled.
  • Partial match display: Most browsers show options that contain the typed text anywhere (not just starting with it).
  • Showing all options: Clicking the small dropdown arrow (if visible) or double-clicking shows all options in most browsers.
